# 2026-10-21: WebとPDFで実績原稿を共有する

状態: 原稿共有とPDF生成は採用。Web表示は [インライン実績セクション](2026-10-21-inline-portfolio-section.md) で更新。

## 背景

個人の仕事の実績をWebの正本から更新し、提出用PDFにも同じ変更を反映する必要がある。名刺アプリとしての既存UIと非公開連絡先の境界も維持する。

## 判断

型付きの3言語コンテンツと共通のAstro文書コンポーネントを採用する。事例は背景・課題、私の役割、取り組んだこと、実現したこと・成果物、関連リンクの5項目で統一する。

提出用PDFは印刷専用経路をChromiumで印刷して生成する。サイトのスクリーンショットをPDFに並べず、本文の検索・選択とリンクを維持する。印刷専用CSSで表紙と各事例の改ページを制御する。

日本語PDFをビルドごとに生成する。日本語フォントは依存パッケージから配信し、外部フォントサービスや実行環境のフォント構成に依存しない。日英中Webには、提出用PDFが日本語であることを明示する。

## 結果

本文の編集箇所は一つになり、ビルドにはChromiumが必要になる。CIでブラウザを明示的に導入し、公開ファイルと提出用ファイルを同時に生成する。PDF公開と実績Web公開は通常のサイトCDに従う。
