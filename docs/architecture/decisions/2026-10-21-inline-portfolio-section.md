# 2026-10-21: 実績をプロフィール末尾に置く

状態: インライン表示は採用。カード枠とPDFは [ブラウザ印刷と統一カード](2026-10-21-native-print-and-record-panels.md) で更新。

## 判断

本人の指定により、専用の長文実績ページを廃止し、プロフィールの学歴・資格の後に実績セクションを置く。FUKU、D6E、ホワイトハッカーの3項目を大きなLucideアイコンと短い概要で示し、各項目は関連する公開サイトや記事へ直接リンクする。

スマートフォンではアイコンと概要を横に、広い画面では3項目を横並びにする。既存の白背景とcornflowerblueを使う。

## PDFとの関係

Webで表示する概要は共通実績データの `overview` に置き、PDFの事例概要にも同じ文を使う。提出用PDFの詳細記載と再生成機構は維持する。旧実績ページURLはプロフィール末尾へ308リダイレクトする。
