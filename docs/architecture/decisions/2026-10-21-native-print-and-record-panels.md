# 2026-10-21: ブラウザ印刷と統一カード

状態: 採用

本人の指定により、実績カードの見出しを学歴・資格と同じ `record-panel`、`header`、`row-icon` で構成する。実績の見出しにはLucideのBriefcaseBusinessを使用する。

PDFダウンロード、専用印刷ページ、別原稿、ビルド時のPDF生成を廃止する。ブラウザの印刷機能で表示中のプロフィールを印刷・PDF保存する。`@media print` でヘッダー、フッター、操作ボタンを非表示にし、カードの途中での改ページを避ける。

旧生成済みPDFは公開ディレクトリから退避し、既存のローカル成果物は保存する。
