# 実績と印刷

実績は `/{locale}#portfolio` に表示する。原稿の正本は `src/content/portfolio.ts`。FUKU、D6E、ホワイトハッカーの見出し・短い概要・公開リンクを日英中で管理する。

学歴・資格・実績は、同じ `record-panel` と見出しの `row-icon` を使う。実績の本文は `PortfolioSection.svelte` で表示する。

実績はPCで2列、スマホで1列。3件目は次の行へ折り返す。各実績のLucideアイコンはカラム上部の中央に置き、説明文は左揃えとする。印刷も2列に揃える。

印刷はブラウザの標準機能を使う。Webと別の原稿・ページ・PDFダウンロードは設けない。`src/styles/print.css` で操作UIを隠し、カードの分断を防ぐ。名刺は表示中のカードを印刷する。

通常ビルドにChromiumやPDF生成は不要。旧 `/{locale}/portfolio` はプロフィール末尾へ308リダイレクトする。

非公開連絡先の表示条件は通常画面と同じ。公開ページには含めず、本人が認証済みの非公開ページを印刷する場合だけ表示される。
